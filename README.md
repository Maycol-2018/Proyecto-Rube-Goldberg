# Máquina de Rube Goldberg ⚙️

Proyecto práctico desarrollado en **Unity 6** como ejercicio de aprendizaje para explorar el sistema de físicas 3D, simulación de colisiones en cadena y configuración de componentes (`Rigidbodies`, `Colliders` y `Hinge Joints`).

## 🚀 Características
* **Simulación física:** Secuencia continua de colisiones en cadena controladas 100% por el motor de físicas de Unity.
* **Diseño visual:** Entorno básico estructurado con primitivas 3D y materiales con texturas aplicadas.

## 🛠️ Requisitos
* **Motor:** Unity 6 (versión 6000.6.6f1 o superior).
